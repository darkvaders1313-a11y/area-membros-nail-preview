# Área de Membros · Nail Design

Design simples: 3 botões na home, depois módulos e aulas com link direto.

## Abrir

Abra o arquivo `index.html` no navegador  
ou rode:

```bash
python3 -m http.server 8765
```

Acesse: http://localhost:8765

## Como funciona

1. **Início** — 3 botões grandes  
2. **Cursos** — lista por passo (Base → … → Bônus)  
3. **Módulo** — cada aula com o nome e o link do Drive  
4. **Cílios** e **Ferramentas** — mesma lógica, botão = abrir  

## Arquivos

- `index.html` — página  
- `styles.css` — visual limpo (branco / verde / azul)  
- `data.js` — módulos + links das aulas  
- `app.js` — navegação entre telas
